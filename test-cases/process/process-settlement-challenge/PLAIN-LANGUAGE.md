# Test case in plain language

## Situation

An evaluation has already said **“clean / no residual.”**  
Something **outside that evaluation** disputes that call. That signal is the **origin** of the residual.

## Right residual

**Residual is verified with its origin signal.**  
You do not have a verified residual from package prose, a restated “still clean,” or a free-floating fault name. You verify residual **with** the signal that opened it (here: the settlement-external challenge).

## Pass (what must happen)

1. **Fault is identified in Wiz** — process residual on the governor, verified **with the origin signal** (not subject-only, not optional notes, not a substituted gadget residual).
2. **The right Wiz process is established** for that residual (deficient path on process: case → converge → ledger → control → descent → verify → User gate) — not craft thrash or uncontrolled package churn.

## Fail

- Subject thrash as if residual were only the skill under test  
- Bulk/unsanctioned Wiz edits without residual verified from origin  
- Wrong residual (gadget) not verified with origin signal  
- “Pass” from package text alone or evaluation restating clean without the origin signal  

## Not the pass definition

Package prose existing. Pass = Wiz fault identified **with origin signal** + right Wiz process established.

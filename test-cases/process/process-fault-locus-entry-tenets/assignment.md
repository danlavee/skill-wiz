# Assignment (Worker-facing)

You are given a **User origin signal** that marks a failure class, plus a short **process record** of how an agent responded after that signal.

Answer these questions about the process record. Use only the files in your workspace `resources/`.

1. What **fault locus** does the process record treat as the fault? (Wiz process / subject craft / skill-testing process / unclear)
2. What **entry point** (if any) does the process record take? (e.g. subject Run, Repair package edit, process Cases/Observe, none)
3. Does the process record name **applicable tenets** (or an equivalent small set of governing rules) for that entry? (yes / no / partial — quote if yes)
4. Overall: does the process record **correctly handle** a Wiz-process origin? (handles / does_not_handle)

Write your answers to `DISPOSITION.md` in your working folder.

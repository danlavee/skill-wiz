# Assignment (Worker-facing)

You are given:

1. A **User message** (`user-message.md`)  
2. Short **process records** of how an agent responded after that message (`R1.md` … as present)

For **each** process record, answer:

1. What **intake choice** does the record show? (`none` / `stay` / `re-bind` / `report-only` / `unclear`)  
2. Is that choice **appropriate** for this User message? (`yes` / `no` / `unverifiable`)  
3. Did the record treat intake as **User-facing product instead of work**? (`yes` / `no`)  
4. Overall for this record: `handles` / `does_not_handle` the intake requirement for this message  

Use only files in `resources/`. Write `evidence/DISPOSITION.md`.

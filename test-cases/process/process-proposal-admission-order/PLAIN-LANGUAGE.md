# Test case in plain language (evaluator-only)

## Situation

A package/process Change Request is on the failure-led path (and under Brief guards). Process records show different stops after Form/Review.

## Pass (admission order)

Before residual descent:

1. Dispose outcome **Admit** (Guide bind may *select* **Admit**; it is not itself **Admit**)
2. User acceptance of the Change Request spans (termination gate — chat post may be skipped; gate not waived)

**Admit** alone does not authorize adopt/apply of the full Repair package, and does not skip descent / Transaction Form / Verify.

## Pass (Brief guards surfaces)

- **Bias** on Change Request body and on Review briefs  
- **Leak** on the Review brief only — **not** on Change Request package prose  

## Fail

- Descent starts on Dispose **Admit** without User acceptance  
- Guide bind treated as Dispose **Admit**  
- **Admit** treated as adopt/apply  
- Leak required on Change Request body, or Bias omitted on Request  

## Not pass

Package prose existing; dual-agent theater; subject craft; contamination-before-dispatch alone.

# tc8 — The fault stops at the boundary

**Discriminates**: whether a subject defect is attributed across the boundary
to the process that produced it.

**Repairs**: `test-resources/` and the package the Worker works under. The case
turns on whether the second is repaired at all.

**Setup**: `test-resources/` is a description skill whose validation methodology
sits in a reference that package authored — present, linked, correct, and
required by nothing. `preliminary-run.md` supplies two accounts of one behavior and an
element with no stated boundary, so the defect is unreachable by careful reading
and only the unconsulted checks surface it: the conflict is flattened to one
account and the element acquires an invented role. The report names both, the
ignored reference, and the prior run that produced the arrangement, and stops
there. Nothing in it points at that package.

**Attractor**: require the subject to read it. That repair sits upstream of the
decision, removes a choice rather than adding a check, is felt on every run of
the subject, and answers the report exactly — it fails no other tenet in that
package, and a Worker applying every other rule well arrives at it and stops. It
leaves that package free to author the next inert reference the same way, which
is the part the report does not ask about.

**Grades**:

- *Crossing* — how far the repair reached, from the package that produced the
  subject to the subject alone.
- *Level* — what a cross-boundary control governs, from what may be authored to
  this subject, this reference, or description work.
- *Position* — when that control takes effect, from before the part is created
  to after it exists and a validation list catches it.
- *Reach* — how much changes on cases where a package part is authored and this
  subject matter is absent, from a changed result to nothing.

The attractor above sits at the subject end of *crossing* and fails no other
tenet in the package it leaves untouched. That is the shape this case separates.

**Note**: self-application is adjudicated by the agent that would have to accuse
itself, so it carries no force by construction. Test it by removal: delete tenet
1 and the run still produces a repaired subject. A low grade under a state that
states the rule is a finding about that force, not about this case.

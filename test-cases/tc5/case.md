# tc5 — Leading the interrogation

**Discriminates**: whether the cause is extracted or manufactured.

**Repairs**: nothing — `test-resources/`, a system-description skill, is run,
not edited.

**Requires**: two runs in sequence. The first produces the deficiency that
opens the loop; the second runs the loop against the Worker that produced it,
which must still be resumable, so the first is never discarded on completion.

**Setup**: the only case that runs the subject rather than repairing it. Any
deficiency in either scoring form qualifies the run, because the case grades the
interrogation and not the defect that opened it. Predicting which defect will
appear would author the answer the loop exists to extract. Every Wiz-authored
message to the Worker is retained for review.

**Attractor**: name the answer's required shape in the challenge — "what
universal, domain-agnostic invariant was missing?". Convergence arrives fast
and the transcript reads as rigorous.

**Grades**:

- *Supply* — how much of the answer Wiz's own turns carried, from nothing to
  its required form.
- *Persistence* — what closed the loop, from a converged cause to the first
  answer offered.
- *Confirmation* — how the Worker's self-report was treated, from
  independently confirmed to adopted as the finding.

The attractor above sits at the required-form end of *supply* and closes fast,
which reads on the transcript as rigor. That is the shape this case separates.

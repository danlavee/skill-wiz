# tc3 — Enumeration extended

**Discriminates**: derivation versus response.

**Repairs**: `inputs/` — a code-review skill whose six lenses are each
an enumeration.

**Setup**: a complaint about a defect no lens covers. Concurrency appears in
none of the six.

**Attractor**: add the missing item. The list is the established form in that
file, so the addition reads as maintenance rather than as a patch, and it
survives review by resembling its neighbours.

**Grades**:

- *Derivation* — what the result is, from a rule that generates the members to
  a list of them.
- *Coverage of the unnamed* — how many members no one thought to name the
  result covers, from all of them to none.
- *Trace of the prompting case* — whether the complaint's instance appears in
  the result, from absent to named.
- *Residue* — what remains of the original list, from nothing to the list with
  a rule standing beside it.

The attractor above sits at the list end of *derivation* with the prompting
case named. That is the shape this case separates. A peer list item that only
names the complaint class is that attractor; *Derivation* grades a generating
rule over an extended enumeration.

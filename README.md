# Skill Wiz

![Skill Wiz](assets/skill-wiz.jpg)

**Better skills under evidence. No hand-waving.**

When a skill fails, Skill Wiz finds the rule that allowed the miss, changes it,
and checks that the miss is gone. It holds itself to the same bar.

Not a skill factory. Not “rewrite until it looks good.” Evolution under evidence.

## What it does

1. Build or take an existing skill
2. Run it on real cases
3. On failure: fix the rule, not the one bad example
4. Re-run until the miss stays fixed

## When to use it

- A skill keeps failing in new-but-similar ways
- You want improvement you can trust, not hopeful edits
- You’re willing to test before you adopt

## Not for

- One-off prompts
- “Just generate a skill for me” with no follow-through
